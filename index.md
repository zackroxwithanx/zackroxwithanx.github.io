## Favorite CPSC 120L Labs

Lab 4 Part 2
I had fun coding this lab with my partner because my partner and I worked well

Lab 6 Part 2
I enjoyed this lab because we got to code the card game of Blackjack. We had to 
assign values to each card type so that the computer would know how to add each
different type of card, whether it be a face card, a number card or an ace. 
I enjoyed practicing if statements and use the || operator we learned about 
earlier in class.

Lab 7 
This lab was fun because we got to apply what we learned in class into code that 
responded to a 
real life situation that we encounter when parking in public. We learned how to 
apply if statements to see if parking was allowed during certain times. This lab 
was straightforward for the most part, but we did find challenge when there was 
parking constraint that wasn't at a full hour and had one at an hour and a half 
so we had to change the if statement to account for the extra 30 minutes.
